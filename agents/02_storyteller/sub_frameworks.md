# Role: Narrative Framework Library

Industry-specific storytelling structures available to Agent 2.

## SCQA
Situation -> Complication -> Question -> Answer. Best for consulting and problem-solving stories.

## Problem-Solution
Define the pain, then present the solution. Best for product pitches.

## Vision-to-Execution
Start with the vision, then show the roadmap. Best for strategy decks.

## YC Pitch Structurer
Problem -> Solution -> Market -> Product -> Traction -> Team -> Ask. Best for fundraising.
