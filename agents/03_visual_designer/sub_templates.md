# Role: Layout Component Library

Reusable slide layout components available to Agent 3.

## Cover
Full-screen title with a single visual focus.

## Metric Showcase
Large number + label + caption. Best in exec/hook contexts.

## Split Compare
Two-column contrast (old vs new, pain vs gain).

## Three-Column Bento
Modular grid for dense multi-point content.

## Timeline
Horizontal progression for roadmaps and milestones.

## Diagram + Data
Left diagram, right data table. Best for consulting reports.
